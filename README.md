# 🇮🇳 Telugu & Tenglish Sentiment Analysis AI

An AI-powered web application built using **Python, Streamlit, and Google Gemini/Gemma API** to analyze Telugu and Tenglish (code-mixed Telugu in English script) social media comments.

### 🚀 Live Demo
👉 **[Click here to try the Live Web App](https://streamlit.app)**

### ✨ Key Features
* **Regional & Tenglish NLP:** Understands native Telugu script as well as Tenglish slang (e.g., *"Super anna, full support"*).
* **Sarcasm Detection:** Identifies subtle cultural sarcasm and mixed sentiments accurately.
* **Bilingual Explanation:** Explains the reasoning behind the sentiment in both English and Telugu.

### 🛠️ Tech Stack
* **Frontend:** Streamlit
* **AI Model:** Google GenAI SDK (`gemini` / `gemma` models)
* **Deployment:** Streamlit Community Cloud & GitHub
